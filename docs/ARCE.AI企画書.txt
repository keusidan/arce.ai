・Search表示(ボタン式の文字(タップすると検索したリンク一覧を展開する))

#アーティファクトの詳細な機能
・アーティファクト生成中でもプレビューを表示可能にする。
・AIがコードを生成している途中でも、生成済みのコードをリアルタイムでプレビューへ反映する。
・コードが追加・変更されるたびにプレビューを自動更新する。
・HTML/CSS/JSなどのプレビュー可能な形式は、生成完了を待たずに動作確認できるようにする。
・生成途中のアーティファクトでも、可能な範囲で操作できるようにする。
・生成中のプレビューと生成完了後のプレビューを同一画面で扱えるようにする。
・コードが不完全な状態でも、可能な範囲までプレビューを表示する。
・生成途中にエラーが発生した場合、プレビュー上にエラーを表示する。
・エラー内容をAIの修正処理へ渡せるようにする。
・プレビューは差分更新などを利用し、生成中の端末負荷を抑える。

#チャット指示によるファイル・アプリ生成
・APK、EXE、JAR、JSON、PY、HTML、JS、CSSなどの生成形式をチャットの指示から決定できるようにする。
・「Androidアプリを作ってAPKにして」などの自然言語による指示から、必要な生成形式を判断する。
・ユーザーが生成形式を指定していない場合は、チャット内容から適切な形式を判断する。
・生成形式の判断が難しい場合は、チャット上に確認用の質問タイルを表示する。
・APK/EXE/JARなど、ビルドが必要な形式はコード生成だけで終了せず、可能な範囲でビルドまで自動実行する。
・ビルドに必要なSDK、コンパイラ、Gradleなどが利用可能か自動確認する。
・必要な環境が不足している場合は、不足している環境をチャット上に表示する。
・生成・ビルド中は進捗状況をチャット上に表示する。
・生成完了後は、生成されたファイルをアーティファクトから操作・保存できるようにする。
・生成されたアプリやファイルの内容を、完成前から可能な範囲でアーティファクト上にプレビューできるようにする。

#その他の必要要素
・チャットによる天気、時間を取得できるようにする。
・GoogleだけでなくYahooやDockDockGoでもサーチをかけれるようにする。
・Apk,exe,jar,json,py,html,js,cssを生成できるようにする。
・AIモデルをダウンロードした時、再インストールはせず維持する。

#必要なソフト、ライブラリ
・推論エンジン: llama.cpp(GGUF形式対応、CPU/Vulkan/OpenCL/Metal対応)、または MLC-LLM(モバイル最適化・NPU対応強化)
・Android開発環境: Android SDK / NDK、Gradle(APKビルド用)
・UIフレームワーク: Jetpack Compose または Kotlin + XML(ネイティブUI)、WebView(アーティファクトのHTML/JSプレビュー用)
・GPU計算: Vulkan API または OpenCL(GPU推論用)、NNAPI(対応端末でのNPU利用)
・バックグラウンド処理: Android WorkManager(生成中のバックグラウンド実行・通知連携)
・ファイル管理: Scoped Storage API(モデルファイル・生成ファイルの保存管理)
・検索連携: DuckDuckGo Instant Answer API、Yahoo検索API(または非公式スクレイピング、要規約確認)
・天気・時間取得: OpenWeatherMap API 等の無料気象API(検索用、気象用)
・端末のシステム時計/タイムゾーンAPI
・コード生成・実行補助: Termux相当のシェル環境(exe/jar等の他形式ビルドを視野に入れる場合)、Python同梱ランタイム(py生成物の動作確認用)
・モデル管理: Hugging Face Hub API(Qwen/Gemma等のモデルダウンロード元)
