# ARCE.AI チャット画面（0.8.18）

## 変更
- **返信を、Claude のように画面いっぱいの文章にした**：アイコン、「ARCE.AI」の名前、エージェントの名前（「General Chat」など）、時刻、吹き出しの枠をやめた。返信は、思考・道具の表示・本文・操作ボタンを、上から幅いっぱいに並べるだけ。ユーザーの発言だけが吹き出し（右寄せ、幅は画面の 88% まで）。余白も、左右 16 → 12 に狭めた。
- **「考えています」のカードからも、エージェントの名前を消した**（左の余白も、アイコンの分を無くした）。
- **入力欄のモデルのボタン（立方体のボタン）を消した**。モデルの管理は、下のタブとヘッダーのモデル名から開ける。
- **文字の大きさを設定できる**：設定 → 表示・プライバシー →「文字の大きさ」（85%・100%・115%・130%・150%・175%・200%）。画面全体の文字に効く。端末の文字サイズの設定には、**重ねて**効く（端末が 130% で、アプリが 150% なら、約 195%）。チャットの `update_settings` の `fontScale`（0.7〜2.0）からも変えられる。

## 確認したこと／していないこと
- 確認：文字の大きさが画面全体に効くこと、設定に保存されること、返信にエージェントの名前が出ないこと、モデルのボタンが無いこと（テスト）。
- 未確認：実機での見え方（特に、長い返信と、コードのカードの幅、文字を 200% にしたときの設定画面の崩れ）。
